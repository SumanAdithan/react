By default your bundler puts the whole app into one bundle that loads up front. **Code splitting** breaks it into chunks that are downloaded on demand.

## React.lazy

```jsx
import { lazy, Suspense } from 'react';

// the module is downloaded the first time <Settings /> renders
const Settings = lazy(() => import('./pages/Settings'));

function App() {
  return (
    <Suspense fallback={<p>Loading...</p>}>
      <Settings />
    </Suspense>
  );
}
```

- `lazy` takes a function that returns a dynamic `import()`.
- The lazily loaded module must have a **default export** that is a component.
- `lazy` must be called at **module level**, not inside a component.

## Suspense

`<Suspense>` shows its `fallback` while anything inside it is still loading: lazy components, or [data that suspends](/docs/modern-react/react-19#use).

```jsx
<Suspense fallback={<PageSkeleton />}>
  <Header />
  <Suspense fallback={<Spinner />}>
    <Comments /> {/* can show its own spinner while the rest is visible */}
  </Suspense>
</Suspense>
```

Nest boundaries to control which parts of the page appear together.

## Route-based splitting

The most effective place to split is **per route**:

```jsx
import { lazy, Suspense } from 'react';
import { BrowserRouter, Routes, Route } from 'react-router-dom';

const Home = lazy(() => import('./pages/Home'));
const Dashboard = lazy(() => import('./pages/Dashboard'));

function App() {
  return (
    <BrowserRouter>
      <Suspense fallback={<p>Loading page...</p>}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/dashboard" element={<Dashboard />} />
        </Routes>
      </Suspense>
    </BrowserRouter>
  );
}
```

<Callout>
  Pair `Suspense` with an [Error Boundary](/docs/advanced/error-boundaries), so a failed chunk download (on a flaky network, for example) shows a retry UI instead of crashing.
</Callout>

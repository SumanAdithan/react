React itself only renders UI. Real apps combine it with libraries for forms, data fetching, tables, styling and more. This section covers the most widely used ones.

## The modern React stack

| Problem | Recommended | Alternatives | Page |
| --- | --- | --- | --- |

| Forms | **React Hook Form** | TanStack Form, Formik (legacy) | [React Hook Form](/docs/libraries/forms/react-hook-form) |

## How they fit together

A **single Zod schema** can validate the form (React Hook Form), type the data (TypeScript) and validate API responses (TanStack Query), so the same rules apply everywhere.

<Callout title="Choosing libraries">
  Before adding a dependency, check that it's **actively maintained** (recent releases), **typed** (TypeScript support), **small**, and **widely used**. And ask whether a few lines of your own code would do the job.
</Callout>

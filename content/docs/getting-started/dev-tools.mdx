---
title: React Developer Tools
description: Inspect components, props, state and performance in the browser.
---

Install the **React Developer Tools** extension for [Chrome](https://chromewebstore.google.com/detail/react-developer-tools/fmkadmapgofadopljbjfkapdkoienihi), [Firefox](https://addons.mozilla.org/firefox/addon/react-devtools/) or Edge. It adds two tabs to the browser DevTools:

## ⚛️ Components

- Browse the component tree (not just the DOM tree).
- Select a component to see and **edit** its props, state, hooks and context live.
- Click the `<>` icon to jump to the component's source.
- Click the eye icon to highlight the DOM node a component renders.

## ⚛️ Profiler

- Record an interaction to see **which components re-rendered, how long each took, and why**.
- Turn on *"Highlight updates when components render"* in settings to watch re-renders flash on screen. This helps find unnecessary renders. See [Performance](/docs/advanced/performance).

<Callout title="Redux DevTools">
  If you use Redux, also install the **Redux DevTools** extension to time-travel through dispatched actions. See [Redux Toolkit](/docs/state-management/redux-toolkit).
</Callout>

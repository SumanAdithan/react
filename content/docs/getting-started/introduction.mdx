**React** is a JavaScript library for building user interfaces. Facebook (now Meta) released it as open source in 2013.

## Main features

| Feature | Meaning |
| --- | --- |
| **Component-based** | The UI is split into small, reusable pieces called components. |
| **Declarative** | You describe *what* the UI should look like for a given state; React works out *how* to update the DOM. |
| **Virtual DOM** | React keeps a lightweight copy of the UI in memory and changes only what is different in the real DOM. |
| **One-way data flow** | Data flows down from parent to child through props, which makes changes predictable. |
| **The "V" in MVC** | React only handles the *view* layer. Routing, data fetching and global state come from other libraries or frameworks. |

## Traditional websites vs React apps

<Tabs items={['Traditional (multi-page)', 'React (single-page)']}>
  <Tab value="Traditional (multi-page)">
    1. The browser sends a request to the server.
    2. The server returns a full HTML page.
    3. The browser loads and displays it.
    4. **Each new page sends another request and reloads the whole page.**
  </Tab>
  <Tab value="React (single-page)">
    1. The browser sends **one** request to the server.
    2. The server returns HTML plus a JavaScript bundle.
    3. From then on, JavaScript in the page fetches data (usually JSON) and updates the screen.
    4. **The page never fully reloads**, so navigation feels instant.
  </Tab>
</Tabs>

This model is called a **Single-Page Application (SPA)**. Modern React frameworks such as Next.js combine it with server rendering. See [Server Components](/docs/modern-react/server-components).

## DOM vs Virtual DOM

- **DOM (Document Object Model)**: the browser's tree of HTML elements. Updating it directly and often is expensive, because the browser recalculates layout and repaints.
- **Virtual DOM**: a JavaScript object tree that describes the UI. When state changes, React:
  1. builds a new virtual tree,
  2. compares it with the previous one (the **diffing**, or *reconciliation*, algorithm),
  3. applies only the minimal set of changes to the real DOM (the **commit**).

<Callout title="Render ≠ DOM update">
  "Rendering" in React means *calling your component function* to get JSX. React touches the real DOM only if the result differs from last time.
</Callout>

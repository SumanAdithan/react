## Handling CSS

```bash
npm i style-loader css-loader --save-dev
```

- **css-loader** reads the `.css` file and resolves `@import` and `url()`.
- **style-loader** injects the CSS into the page with a `<style>` tag at runtime.

Loaders in `use: [...]` run **right to left** (bottom to top): `css-loader` first, then `style-loader`.

## Handling Sass / SCSS

```bash
npm i sass sass-loader --save-dev
```

```js title="webpack.config.js"
{
  test: /\.scss$/,
  use: [
    'style-loader',
    'css-loader',
    'sass-loader', // compiles SCSS → CSS (uses the `sass` package automatically)
  ],
},
```

## Extracting CSS into a file

`style-loader` puts CSS inside the JS bundle, so styles only apply **after the JS runs**, which causes a flash of unstyled content. For production, write CSS to a separate `.css` file instead:

```bash
npm i mini-css-extract-plugin --save-dev
```

```js title="webpack.config.js"
const path = require('path');
const MiniCssExtractPlugin = require('mini-css-extract-plugin');

module.exports = {
  entry: './src/index.js',
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, './dist'),
    publicPath: './dist/',
  },
  mode: 'none',
  module: {
    rules: [
      {
        test: /\.css$/,
        use: [MiniCssExtractPlugin.loader, 'css-loader'], // replaces style-loader
      },
      {
        test: /\.scss$/,
        use: [MiniCssExtractPlugin.loader, 'css-loader', 'sass-loader'],
      },
    ],
  },
  plugins: [new MiniCssExtractPlugin({ filename: 'style.css' })],
};
```

Link the extracted file in HTML:

```html title="index.html"
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Document</title>
    <link rel="stylesheet" href="./dist/style.css" />
  </head>
  <body>
    <script src="./dist/bundle.js"></script>
  </body>
</html>
```

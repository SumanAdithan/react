## How to read these pages

- Read **Fundamentals** and **Hooks** in order. Later sections build on them.
- Copy the code blocks into a Vite project (see [Installation](/docs/getting-started/installation)) and change them as you go.
- Each section has ⚠️ callouts for common mistakes and outdated patterns you will meet in tutorials.

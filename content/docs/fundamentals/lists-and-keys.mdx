Use `Array.prototype.map()` to turn an array of data into an array of elements:

```jsx
function Garage() {
  const carList = [
    { id: 1, brand: 'BMW', color: 'red' },
    { id: 2, brand: 'Ford', color: 'green' },
    { id: 3, brand: 'Tesla', color: 'black' },
  ];

  return (
    <ul>
      {carList.map((car) => (
        <li key={car.id}>
          <Car carInfo={car} />
        </li>
      ))}
    </ul>
  );
}
```

## Why keys matter

A `key` gives each item a **stable identity** between renders. During [reconciliation](/docs/getting-started/introduction#dom-vs-virtual-dom) React uses keys to work out which items were added, removed or reordered, instead of treating them all as one undifferentiated list.

- Keys must be **unique among siblings** (not globally).
- Keys must be **stable**: the same item gets the same key on every render.
- Keys are **not passed as props** and don't appear in the HTML.
- Put the key on the **outermost element** returned from `map`.

## Choosing a key

| Source | Good key? |
| --- | --- |
| Database ID (`user.id`) | ✅ Best |
| A unique field (`email`, `slug`) | ✅ |
| Array index (`i`) | ⚠️ Only if the list is static: never reordered, filtered or added to in the middle |
| `Math.random()` / `crypto.randomUUID()` during render | ❌ Changes every render, so React re-creates every item |

<Callout type="warn" title="Why index keys break">
  With index keys, deleting the first item shifts every index. React then reuses the wrong component instances, so input values, focus and component state end up attached to the wrong rows.
</Callout>

## Filtering and rendering

```jsx
const visibleTodos = todos.filter((t) => !t.done);

return (
  <ul>
    {visibleTodos.map((t) => (
      <TodoItem key={t.id} todo={t} />
    ))}
  </ul>
);
```

## Fragments with keys

When each item renders several siblings, use `Fragment` so you can attach a key:

```jsx
import { Fragment } from 'react';

{glossary.map((term) => (
  <Fragment key={term.id}>
    <dt>{term.word}</dt>
    <dd>{term.definition}</dd>
  </Fragment>
))}
```

The standard React testing stack:

| Tool | Role |
| --- | --- |
| **Vitest** | Test runner and assertion library (Jest-compatible API, native to Vite) |
| **jsdom** | Simulates a browser DOM in Node.js |
| **@testing-library/react** | Renders components and queries them the way a user would |
| **@testing-library/user-event** | Simulates realistic user interactions |
| **@testing-library/jest-dom** | Extra matchers such as `toBeInTheDocument()` and `toHaveValue()` |

## Installation

```bash
npm i -D vitest jsdom @testing-library/react @testing-library/dom @testing-library/user-event @testing-library/jest-dom
# or
yarn add -D vitest jsdom @testing-library/react @testing-library/dom @testing-library/user-event @testing-library/jest-dom
```

## Configuration

<Tabs items={['vite.config.js', 'setupTest.js', 'package.json']}>
  <Tab value="vite.config.js">
    ```js title="vite.config.js"
    import { defineConfig } from 'vite';
    import react from '@vitejs/plugin-react';

    export default defineConfig({
      plugins: [react()],
      test: {
        environment: 'jsdom',       // browser-like DOM
        globals: true,              // use test/expect/vi without importing them
        setupFiles: './setupTest.js',
      },
    });
    ```
  </Tab>
  <Tab value="setupTest.js">
    ```js title="setupTest.js"
    import { afterEach } from 'vitest';
    import { cleanup } from '@testing-library/react';
    import '@testing-library/jest-dom/vitest'; // adds toBeInTheDocument() and friends

    // unmount rendered components after each test
    afterEach(() => {
      cleanup();
    });
    ```
  </Tab>
  <Tab value="package.json">
    ```json title="package.json"
    {
      "scripts": {
        "dev": "vite",
        "build": "vite build",
        "lint": "eslint .",
        "preview": "vite preview",
        "test": "vitest"
      }
    }
    ```
  </Tab>
</Tabs>

## Running tests

```bash
npm test                 # watch mode: re-runs on file changes
npx vitest run           # run once (CI)
npx vitest --coverage    # coverage report (needs @vitest/coverage-v8)
npx vitest --ui          # browser UI (needs @vitest/ui)
```

## Where to put tests

Vitest picks up files named `*.test.jsx` / `*.spec.jsx` anywhere, or files inside a `__tests__` folder:

  CRA came preconfigured with **Jest** + Testing Library: run `npm test`, put tests in `__tests__/` or name them `*.test.js`. The test code is almost identical. Replace `vi.fn()` with `jest.fn()`, and you don't need the Vite config.
</Callout>
